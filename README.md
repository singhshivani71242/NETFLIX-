
# 🎬 Netflix Clone

A Netflix-inspired landing page built using **HTML5 and CSS3** as a frontend web development practice project.

## 🌟 About the Project

This project recreates the look and feel of the Netflix India homepage. It includes a hero section, navigation bar, membership call-to-action, feature sections, FAQs, and footer.

## 🚀 Features

- Netflix-inspired homepage design
- Navigation bar with language and sign-in buttons
- Hero section with email input and Get Started button
- Multiple content sections with images and videos
- Frequently Asked Questions section
- Responsive layout using CSS media queries
- Custom styling with Google Fonts

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, and responsiveness
- **Google Fonts** – Typography

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
